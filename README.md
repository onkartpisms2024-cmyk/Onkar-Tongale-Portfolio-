# Onkar Tongale — Marketing Portfolio

A dark, cinematic, mobile-first portfolio for Digital Marketing, Content Creation, Performance Marketing and Sales.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — scroll reveal and mobile navigation
- `assets/onkar.jpg` — hero portrait
- `assets/zerob.mp4` — ZeroB product visual
- `assets/tulsi-chai.mp4` — Tulsi Chai brand visual
- `assets/bike.mp4` — personal visual / Beyond Work

## Deploy
This is a static website, so it can be deployed with GitHub Pages, Vercel or any static hosting service.
